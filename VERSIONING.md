# Versioning

The webapp uses `major.feature.update` versions.

- Increment `feature` and reset `update` to `0` whenever a new tool is added.
- Increment `update` for fixes, refinements, and other changes to existing tools.
- Increment `major` only for a future incompatible application generation.

The ZvZ Infographic introduced version `1.9.0`. Its subsequent refinements are tracked by the current `1.9.x` version.
